## Prepared installation path

`bootstrap-ubuntu.sh` configures the official Docker APT repository and installs the Compose plugin on a fresh approved Ubuntu VM. It creates a protected `.env` with synthetic-only rules mode, starts the app and Caddy, and waits for a real HTTPS health response. It refuses an existing `.env` or conflicting container packages instead of overwriting an existing deployment. The installer has not been executed on a Vultr VM.

Select a reviewed commit, configure the Vultr firewall (public TCP 80/443; SSH restricted to the administrator's approved source), clone into `/opt/ledgerpilot`, and run from the checkout:

```sh
sudo bash deploy/bootstrap-ubuntu.sh ACTUAL_PUBLIC_HOSTNAME
```

An existing domain can be used. For a temporary public demo, `ledgerpilot.ACTUAL_IPV4.sslip.io` can avoid buying a domain: the service maps hostnames containing an IP to that IP and supports ordinary TLS issuance through Caddy. Verify DNS and certificate issuance live; public DNS availability is a third-party dependency. Do not substitute a made-up IP.
